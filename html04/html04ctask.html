HTML Tables Task

Practice building data tables with captions, header cells, colspan, and rowspan.

Simple Table

A basic table has a caption, one header row, and data rows.

Remember: Use <th> for header cells and <td> for data cells. Each row goes inside its own <tr>.

___

Table with colspan (Column Spanning)

The colspan attribute makes one cell stretch across more than one column.

Example: <td colspan="2"> makes one cell as wide as 2 columns.

___

Table with rowspan (Row Spanning)

The rowspan attribute makes one cell stretch down across more than one row.

Example: <td rowspan="2"> makes one cell as tall as 2 rows.

___

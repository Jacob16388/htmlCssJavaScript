1. The Content Layer

What is Content?

The content area contains the actual elements like text, images, videos, or child HTML nodes. Its size is controlled using the width and height properties.

2. The Padding Layer

Understanding Padding

Padding creates breathing room inside the element between the content and its border. It inherits the background color of the element.

PADDING AREA
Inner Content

Padding Shorthand

Set padding for all sides at once or individually:

/* Top Right Bottom Left */
padding: 10px 20px 10px 20px;

/* Top/Bottom Left/Right */
padding: 1rem 2rem;

4. The Margin Layer

Outer Spacing

Margin pushes other surrounding elements away. It is completely transparent and sits outside the border.

Centering with Margin

Use margin: 0 auto; combined with a fixed or max-width to center block elements on a page easily.

.container {
  max-width: 800px;
  margin: 0 auto;
}

5. Box-Sizing: content-box vs. border-box

content-box (Default)

Adds padding and border to the specified width. A 200px box with 20px padding and 5px border becomes 250px wide.

border-box (Recommended)

Includes padding and border within the calculated width. A 200px box stays 200px wide regardless of padding.

* {
  box-sizing: border-box;
}
